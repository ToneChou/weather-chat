# weather-chat

一个**零依赖的单文件** AI 对话框页面，支持「正常 / 雨天 / 雪天」三种外观切换。

页面只做用户消息的发送与展示，**不包含 AI 回复逻辑**，也没有任何后端与网络请求。

## 效果

### 正常

紫蓝渐变背景，无任何粒子特效。

### 雨天

- **三层景深**的雨滴：远处的细、淡、慢，近处的粗、亮、快
- 雨丝带轻微东风倾角，视觉朝向与实际下落方向保持一致
- 雨滴落到「地面」（底部输入区顶边）会溅起水花：向上飞散的小水珠 + 贴地扩散的椭圆涟漪

### 雪天

- 三层景深的雪花，远景为小圆点、近景为缓慢自转的六角晶体
- 底部有初始雪地，雪花落下会**让积雪慢慢累积变厚**
- 按住鼠标左键在雪地上来回擦拭，可以**擦除积雪**
- 擦雪时光标变为代码生成的**扫帚**：松开时站立，按下时切换为前倾的扫雪姿态

## 运行

直接双击 `index.html` 即可，也可以用任意静态服务器：

```bash
python -m http.server 8000
# 打开 http://localhost:8000/
```

无需构建，无需安装依赖。

## 实现要点

**动画与刷新率解耦**

所有位移都是「像素/秒 × 真实帧间隔」，而不是「每帧固定像素」。因此 60Hz 与 120/144Hz 屏幕上的速度表现一致，切到后台再切回来也不会因为时间累积而瞬移。

**积雪用一维高度图**

地面按 4px 一列切分，每列记录一个积雪厚度：累积是加、擦除是减、绘制是把高度图连成雪坡曲线。每帧对高度图做一次轻微扩散松弛，模拟雪的自然休止角，避免随机落点堆出尖刺。

**旋转中心对准光标热点**

扫帚光标以「刷毛接触点」为旋转中心，换姿势时刷头始终压在热点上，不会错位。

**按下时锁定光标**

擦雪判定依赖实时雪面高度，而擦拭本身正在压低雪面，持续判定会让光标高频闪烁。因此仅在未按下时判定，按下后直接锁定为扫雪姿态。

## 可调参数

在 `index.html` 顶部附近：

| 常量 | 说明 | 默认 |
|------|------|------|
| `MAX_DEPTH` | 积雪厚度上限 | `55` |
| `INITIAL_DEPTH` | 初始雪地厚度 | `14` |
| `ACC_PEAK` | 单片雪花的累积贡献，越大积雪越快 | `0.9` |
| `ERASE_RATE` | 擦除速率（像素/秒） | `210` |
| `BRUSH_R` | 擦雪笔刷半径 | `44` |
| `COL_W` | 积雪高度图列宽 | `4` |

雨雪的疏密、速度与景深分层分别由 `RAIN_LAYERS` 和 `SNOW_LAYERS` 控制。

## 说明

- 仅前端演示：**没有 AI 回复**，无后端、无网络请求
- 主题选择与聊天记录保存在浏览器 `localStorage`，刷新不丢，但不会同步到服务器
- 不引用任何外部资源（无 CDN、无外链字体、无图片文件），图标均为内联 SVG 或 Canvas 绘制
